### PG-R04 道具渲染、摆放与重画

- [ ] 子需求完成（仅产品验收通过后勾选）
- 来源：需求 v0.2 §4.5、§4.7、§7（[需求说明](../需求/道具生成.md)）
- 协作状态 / 优先级 / 认领状态 / 唯一主负责人 / 分角色协作人 / 验收人：待验收 / P0 / 已认领 / 负责人：Claude / 无 / 用户
- 验收：
  - 成功：生成好的道具用手绘笔触画在预演里，跟着运镜移动、按景深虚化，深色主题和夜景下可见。
  - 手持：`hand` 道具的握持点对准空着的手；伞（左手）、手机（右手）都占用时改放脚边。
  - 归属：有 `props` 的镜头里，道具只出现在归属的人身上，不再所有人共用一把伞。
  - 地上：放在归属人脚边外侧；没有归属时放在人物层的空位；脚在画框外时不画。
  - 占位：生成中或失败显示带名字的手绘小方块；画好后替换，其他线条不闪。
  - 重画：长按预演画面弹出本镜道具列表，点「重画」重新生成并替换；所有剧本里的这个道具一起变。
  - 平台：Android；Web 构建通过。
- 认领时间 / 交接确认 / 工作分支或 PR：2026-11-07 / 无 / develop
- 实施结果 / 验证结果 / 产品验收 / 完成日期：已实现 / 完整档通过 / 待验收 / —
- 关联设计、工程规范、主规格与进行中变更：[UI 规范](../../development/ui.md)；镜头预演 PV-R03（`figure_pose.dart`、`sketch_figure.dart`）
- 当前实现、目标、范围与非目标：现状道具由 `figureAction` 按关键词得出、同镜所有人共用。目标：有 `props` 时按人分配内置道具和生成道具，画出生成道具，提供重画入口。非目标：桌面 / 墙面摆放（Q4，先按地上）、道具带姿态（Q6）、道具动画。
- 依赖与接口契约版本：依赖 PG-R03
- 原文要求与工程建议的区分：摆放规则出自需求 §4.5；「重画入口改为长按画面弹出本镜道具列表」是工程调整（需求写的是长按道具，道具很小时难点中），需用户确认；「道具用单独的笔、种子按道具名」是工程建议
- 技术任务权威位置（如适用）：本卡（方案 2026-11-07 经用户批准）
- 技术方案摘要：
  - 新增纯函数 `pages/preview/prop_layout.dart`：`assignProps(shot)` 把 `props` 分到每个人物（伞 / 黑伞 / 手机转成内置道具，其余为生成道具）；`placeProp(...)` 按 anchor、握持点、空闲的手和构图算出道具在画框里的矩形，脚在画外时返回 null。旧数据没有 `props` 时走现有关键词逻辑。
