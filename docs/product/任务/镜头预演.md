  - 2026-11-07 木偶人和姿态库（需求 v0.5）：新增纯函数模块 `pages/preview/figure_pose.dart`：`figureAction` 按关键词得出姿态（站 / 走 / 坐 / 挥手 / 背影 / 回头）、视线（正视 / 抬头 / 低头 / 对视 / 看不清脸）和道具（伞、黑伞、手机），`poseSkeleton` 算人体坐标下的关节位置（含呼吸、走路摆动、挥手摆动），`umbrellaShape`、`headTurn` 给绘制用。`paintSketchFigure` 改画木偶人：体块四肢 + 关节球、胸腔 / 骨盆两块躯干，头部按姿态画正脸 / 侧脸 / 后脑，五官随视线移动。
