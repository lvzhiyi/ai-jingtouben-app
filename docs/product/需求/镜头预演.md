# 镜头预演 · 需求说明

- 状态：已评审（Q3、Q4 待确认，不阻塞开工）
- 版本：v0.5（2026-11-07，人物改为木偶人，按画面描述的关键词摆姿态、拿道具、定视线，不调模型）；v0.4（2026-11-07，用户要求运镜「接近真实视频的表现」，不调付费模型：画面按深度分层，推改为机位前进、摇和移按有无视差区分、加景深和缓动）；v0.3（2026-11-07，用户要求预演画面「更明显、不简陋」：加大运镜幅度，改手绘分镜风格，加取景参照、景别小图、场景模板和淡入转场）；v0.2（2026-11-06）确认 Q1 / Q2 / Q5 / Q6；v0.1 为会话中整理，非外部 PRD
- 拆解：模块卡见[镜头预演任务卡](../任务/镜头预演.md)
- 关联：[README](../../../README.md)、[架构说明](../../architecture.md)、[接口联调约定](../../development/api-integration.md)

## 1. 背景与问题

镜头本现在把故事拆成一张张文字镜头卡（景别、画面、对白、出场角色、理由），然后拼出即梦 / 可灵提示词让用户去生成视频。问题在于：

- 用户只看文字，**感受不到镜头效果**：「近景」和「特写」差在哪、连续几个镜头的节奏顺不顺，要等花钱、花时间生成视频后才知道。
- 生成一次视频成本高、等待久，节奏和构图的问题发现得越晚，返工越贵。

## 2. 目标

在生成视频之前，让用户用几十秒**直观看到整份分镜的构图、运镜和节奏**，确认没问题再去生成。

- 不调用任何图片 / 视频生成模型，完全在客户端用动画渲染示意画面（符合第一版「不做图片视频生成」的范围约定）。
- 离线可用，零额外成本，打开即播。
- 预演用到的新字段（运镜、时长）同时用于提示词，一份数据两处复用。

### 不做（本期）

- AI 生成画面或视频；接 ai-tools 的真实素材（列入后续，见第 9 节）。
- 导出 GIF / 视频文件。
- 语音朗读（TTS），列为可选增强。
- 多人协作、云端分享。

## 3. 用户与场景

- **主要用户**：用 AI 工具做短剧 / 短视频的个人创作者，分镜经验不多。
- **场景 1**：生成完分镜，点「预演」从头播一遍，觉得开头三个中景太平，回到分镜页把第 2 镜改成特写，再预演确认。
- **场景 2**：某段对白很长，预演时字幕没放完就切了，拖长该镜头时长。
- **场景 3**：给合作者讲方案时，直接在手机上播预演。

## 4. 功能需求

### 4.1 入口

- 分镜页顶部操作区新增「预演」入口，进入镜头预演页（`pages/preview/`）。
- 分镜为空或正在流式生成时入口禁用，不预演半成品。
- 镜头卡上提供「从这里预演」，从该镜头开始播放。

### 4.2 示意画面（每个镜头一帧）

| 元素 | 规则 |
| --- | --- |
| 画幅 | 固定 9:16 竖屏画框（短剧主流比例），四周留黑边 |
| 风格 | 手绘分镜：纸底、带抖动的铅笔线、淡彩；深色模式用深色纸底（v0.3） |
| 背景 | 按画面描述关键词选场景模板：街道、车站、室内、自然、车内、手机屏幕、空旷（默认）；识别雨、雪、夜晚（夜景深底浅线、亮窗和路灯）。匹配前去掉出场角色名（v0.3） |
| 人物 | 每个出场角色一个手绘木偶人（v0.5：胸腔、骨盆两块躯干，四肢是体块、关节是圆球），衣服颜色由角色名稳定派生（8 档色相），长短发按名字固定；近景以上画五官；站着有呼吸起伏；剪影下标角色名；没有出场角色时只画场景，手机屏幕场景画一部手机。姿态、道具和视线见 4.3.1 |
| 取景参照 | 三分线和四角取景标记；推拉时标记收放，摇 / 移 / 跟 / 升降时箭头划过（v0.3） |
| 景别小图 | 角落画全身人形和取景框，下方写「腰部以上」等说明（v0.3） |
| 景别 | 由剪影在画框中的占比体现，见 4.3 |
| 画面描述 | 画框上方小字显示 `scene` 文案，可在设置里关闭 |
| 镜头信息 | 角标显示「镜头 n / 总数 · 景别 · 运镜」 |

### 4.3 景别构图规则

人物剪影高度占画框高度的比例（数值为初始设定，实测后调整）：

| 景别 | 剪影占比 | 可见部分 |
| --- | --- | --- |
| 大远景 | 约 8% | 极小人物 + 大面积环境 |
| 远景 | 约 15% | 全身，环境为主 |
| 全景 | 约 55% | 完整全身 |
| 中景 | 膝盖 / 腰部以上 | 半身 |
| 近景 | 胸部以上 | 头肩 |
| 特写 | 面部占满画框宽度 | 面部 |
| 大特写 | 局部（眼睛 / 手）放大，超出画框 | 局部细节 |

### 4.3.1 姿态、道具和视线（v0.5）

按画面描述里的关键词本地匹配（先去掉角色名），同一镜里出场的人共用一套；没有命中时站着、正对镜头。

| 类别 | 取值 | 关键词举例 |
| --- | --- | --- |
| 姿态 | 背影 | 背影、背对、离开、走远 |
| 姿态 | 回头（背对镜头、露侧脸） | 回头、回望、转身 |
| 姿态 | 坐（身后画凳子，手放膝上） | 坐 |
| 姿态 | 走（手脚交替摆动） | 走、跑、漫步 |
| 姿态 | 挥手 | 挥手、招手、抬手 |
| 视线 | 看不清脸（脸压暗、不画五官） | 看不清脸、逆光、背光 |
| 视线 | 对视（两人以上，脸转向对方） | 对视、面对面 |
| 视线 | 低头（眼睛画成垂下的弧） | 低头、看手机 |
| 视线 | 抬头 | 抬头、仰望 |
| 道具 | 伞（左手握伞，伞面在头顶）、黑伞 | 伞、黑伞 |
| 道具 | 手机（右手端在胸前，屏幕发光） | 手机 |

坐姿在画框截到身上的景别（中景、近景）里整个人往上提，头留在原来的构图位置。

### 4.4 运镜动画

新增运镜枚举，动画作用在示意画面上，在镜头时长内缓动完成（起步、停下都缓，停下前略冲过约 1.5% 再回正）。

v0.4 起画面按深度分层：天空、远景（远楼、远山、地平线）、中景（墙、立柱、树）、人物层（含脚下地面）、前景遮挡（近处的柱子、枝叶、盆栽，停在画框边上）。每层按自己的深度跟着摄影机缩放和平移：

| 运镜 | 动画 |
| --- | --- |
| 固定 | 不动 |
| 推 | 机位前进：人物放大到约 1.6 倍，前景放大更多并冲出画框，远景几乎不变 |
| 拉 | 推的反过程 |
| 摇 | 镜头转向：各层同样水平平移（画框宽度 ±35%），没有视差 |
| 移 | 机位横移：人物从画框一侧移到另一侧（±30%），越近的层划过得越快 |
| 跟 | 人物在画框里不动，场景按远近不同速度后退，带轻微手持晃动和走路起伏 |
| 升降 | 机位升高并稍往下俯：近处往下沉得多，地平线上移、天空变少 |

景深：远景、全景不虚；景别越近，离人物平面越远的层（远景、前景）越虚，人物平面始终清楚。

模型输出不认识的运镜时按「固定」兜底，并在镜头卡上提示（沿用现有 `warnings`）。

### 4.5 对白字幕

- 对白在画框底部以字幕显示，按时长逐字出现，结束前保留至少 0.5 秒完整字幕。
- 有多个出场角色时，字幕前不强行标说话人（数据里没有说话人字段）。
- 可选：开启后用系统 TTS 朗读对白（本期不做，见第 2 节）。

### 4.6 时长与播放控制

- 每个镜头有时长（毫秒）。模型给出；缺失或旧数据按默认值：
  - 有对白：`max(2 秒, 对白字数 × 250 毫秒 + 1 秒)`，上限 8 秒；
  - 无对白：大远景 / 远景 3 秒，其余 2 秒。
- 每镜开头 0.25 秒从黑场淡入，并显示「镜头 n · 景别 · 运镜」小标约 0.9 秒（v0.3，取代「默认硬切、可选淡入淡出」）。
- 播放控制：播放 / 暂停、上一镜 / 下一镜、底部按镜头分段的进度条（点击跳转）、总时长显示。
- 播完停在最后一帧，提供「重播」。
- 预演中可调当前镜头时长（如 ±0.5 秒步进），立即生效并保存到本地。

### 4.7 编辑回路

- 预演页可直接跳回分镜页对应镜头修改景别、运镜、对白；返回后从该镜头继续预演。
- 景别 / 运镜 / 时长的修改保存到本地，并同步影响提示词。

## 5. 数据与接口变更

### 5.1 本地表（drift）

`shots` 表新增两列，`schemaVersion` 2 → 3：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `cameraMove` | textEnum，默认「固定」 | 运镜 |
| `durationMs` | integer，可空 | 时长；为空时按 4.6 的规则推导，不回写 |

- 补迁移步骤、`app/drift_schemas/` 快照和 `test/data/migration_test.dart` 用例；旧数据迁移后可正常预演。
- 改表后运行 build_runner，不手改 `*.g.dart`。

### 5.2 模型输出

- 服务端 `server/src/storyboard/storyboard.prompt.ts` 的输出字段新增 `cameraMove`（限定在运镜枚举内）和 `durationSec`（1–10 的数字）。
- 客户端逐行解析兼容：字段缺失不算坏行，非法值按兜底处理并记 `warnings`。
- 不新增接口；SSE 协议不变。

### 5.3 提示词模板

- 即梦 / 可灵模板加入运镜占位（如 `[，{cameraMove}]`），时长不进提示词。
- 同时修改 `server/src/templates/prompt-templates.json` 和 `app/assets/prompt_templates.json`，模板 `version` 加 1，CI 会比对两份是否一致。

### 5.4 ai-tools 导出

- `storyboard_json.dart` 导出的镜头 JSON 增加 `cameraMove`、`durationMs`，便于 ai-tools 后续用于图生视频。需与 ai-tools 侧确认字段兼容。

## 6. 非功能需求

- **性能**：预演播放保持 60fps，UI 线程帧耗时 P90 < 8 ms；用 `integration_test` 回放一份固定分镜做帧统计，数字填入 README。
- **一致性**：Android / iOS / Web 表现一致；Web 无 TTS 时不显示该开关。
- **可访问性**：文字跟随系统字号缩放时字幕不溢出；提供「减少动态效果」时运镜动画关闭，只保留切镜。
- **隐私**：预演全在本地，不上传故事或镜头内容；日志不打印对白和画面描述。

## 7. 验收标准

1. 有分镜时可从分镜页进入预演，从第一个或指定镜头开始，按时长自动播放到结束。
2. 7 种景别的剪影占比肉眼可区分，与 4.3 一致。
3. 7 种运镜动画按 4.4 表现；未知运镜按固定处理并在镜头卡提示。
4. 对白字幕在镜头结束前完整显示；无对白镜头不显示字幕区。
5. 旧项目（schemaVersion 2）升级后可以预演，时长按默认规则推导。
6. 预演中改时长、回分镜页改景别 / 运镜后，预演和提示词都同步变化。
7. 流式生成中预演入口禁用。
8. 两份提示词模板一致，CI 通过；app 覆盖率不低于 85%。
9. 预演帧统计数字已写入 README。

## 9. 后续方向（不在本期）

1. **素材版预演**：接入 ai-tools 导回的定妆照 / 镜头图，示意画面替换为真实图片，形成「示意版 → 素材版」两档预演。
2. **语音朗读**：系统 TTS 朗读对白，按朗读时长自动校正镜头时长。
3. **预演导出**：导出 GIF / 短视频，便于分享给合作者。
4. **节奏分析**：统计总时长、景别分布、对白密度，提示「连续多个同景别，节奏偏平」。
5. **单镜头重写**：对单个镜头提出修改意见，只重新生成这一条。
