# UI 规范

## 设计来源

- 没有设计稿和设计工具；视觉参考 iPhone App 的奶油白与浅粉渐变、大圆角卡片和黑色悬浮操作（见 [AGENTS.md](../../AGENTS.md) 冲刺进度 11/1）。
- 以下数值取自代码，是项目统一规则，不是设计原值。

## 主题与样式入口

- 主题/样式入口：`app/lib/resources/theme.dart`（`AppUi` 共享尺寸 + 浅色 / 深色主题）。
- 优先级：页面明确需要的值可以覆盖全局默认值；覆盖值写在页面的组件文件里并说明原因，能复用的提升到 `theme.dart`。

## 色彩、字体、间距

- 主色种子 `#B74364`，强调粉 `#FF8EAB`，墨色（文字、黑色主按钮）`#242326`。
- 浅色背景 `#FFFCF8`；深色背景 `#201C20`；其余色值见 `theme.dart`。
- 圆角：卡片 `AppUi.cardRadius` = 28，输入框 `AppUi.fieldRadius` = 20。
- 按钮文字 15 号 w600；其余字体和间距：待确认（目前写在各组件里，还没统一成 token）。

## 状态与适配

- 普通、聚焦、错误、禁用、加载状态分别核对；未接入的操作不给出“成功”反馈（例如分享只代表面板已展示，Web 复制成功才提示）。
- 生成中禁用会读到半成品数据的操作。
- 适配：手机竖屏为主，支持深色模式；窄屏、文字缩放、iPad 和 Web 宽屏：待确认。
