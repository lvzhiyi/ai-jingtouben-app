# 分镜原生分享

用户已确认：分镜页新增分享按钮，包含镜头内容、角色和即梦／可灵提示词；Android、iOS 通过 Pigeon 调起系统分享面板，Web 复制文本。

采用纯文本分享，便于直接发给协作者或粘贴到生成工具；本次不做 Markdown 文件导出。内容包含项目标题、角色卡、每个完整镜头的景别／画面／台词／出场角色／拍摄理由和实时拼接的双平台提示词。不含原始故事，不写数据库、不记内容日志。

分享入口在分镜页顶栏。加载中、生成中、无有效镜头或模板未加载时禁用；分享处理中防重复点击，失败提示可重试，取消原生面板不提示成功。坏行不导出，部分失败或停止后的有效镜头标注为未完整生成。

Dart 格式化器只生成文本；分享服务负责 Pigeon 与 Web 剪贴板选择；page 注入，独立按钮组件读取 Bloc 快照，避免给高频增量添加整页重建。Android 使用 ACTION_SEND，iOS 使用 UIActivityViewController，并设置 iPad 弹出锚点。Pigeon schema 为唯一接口来源，生成的三个平台文件不手改。
